Apache Iceberg, AWS Glue, and Snowflake.

## Files
- project1.py — PySpark cleaning and transformation script
- snowflake_setup.sql — Snowflake external volume, catalog integration, and Iceberg table setup
- analytics_queries.sql — 9 analytical SQL queries
